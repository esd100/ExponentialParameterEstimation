# literature/ — PDFs the project reads (not committed)

Copyrighted papers live here on the local machine only; this folder is git-ignored except for this README.
What to fetch, with full citations, DOI links and the file name to use, is in `../docs/project/literature-requests.md`.
When a session reads a PDF from here it must, in the same session, update `bibliography.md` (status → CHECKED-PRIMARY)
and any value in `mexp-harness/mexp/tissue_data.py` or constant in the charter that rests on it.

Already on hand: `appliedanalysisLanczos/` (page images of Lanczos, Applied Analysis 1956, pp. 272–279) — kept in its own
folder at the repository root, also git-ignored.
